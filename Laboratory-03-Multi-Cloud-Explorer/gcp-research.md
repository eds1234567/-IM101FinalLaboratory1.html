# GCP Research

## Brief Overview

Google Cloud Platform (GCP) is a cloud computing platform that provides services for computing, storage, databases, networking, security, data analytics, artificial intelligence, and application development. GCP allows organizations to build, deploy, and manage applications and workloads using Google's cloud infrastructure.

## Global Infrastructure

Google Cloud operates a global infrastructure made up of regions and zones. Regions are geographic locations where Google Cloud resources can be deployed, while zones are deployment areas within regions. This infrastructure allows organizations to place workloads closer to users and design applications for availability and reliability.

## Cloud Management Console

The Google Cloud Console is a web-based interface used to manage Google Cloud resources and services. Users can create and configure resources, monitor cloud environments, manage projects, and access different Google Cloud services through the console.

## Four Core Services

### 1. Compute Engine

Compute Engine provides virtual machines that allow organizations to run applications and workloads on Google's cloud infrastructure.

### 2. Cloud Storage

Cloud Storage is an object storage service used to store and retrieve data such as files, backups, media, and other unstructured data.

### 3. Virtual Private Cloud (VPC)

Google Cloud VPC provides networking capabilities that allow organizations to connect and manage cloud resources within virtual networks.

### 4. Google Kubernetes Engine (GKE)

Google Kubernetes Engine (GKE) is a managed Kubernetes service used to deploy, manage, and scale containerized applications.

## Three Advantages

1. **Strong Data and AI Capabilities** – Google Cloud provides services and technologies that support data analytics, artificial intelligence, and machine learning workloads.

2. **Kubernetes Expertise** – Google Cloud provides Google Kubernetes Engine (GKE), a managed Kubernetes service for deploying and managing containerized applications.

3. **Global Infrastructure** – Google Cloud operates infrastructure across multiple regions and zones, allowing organizations to deploy applications in different geographic locations.

## Typical Enterprise Use Cases

GCP can be used by enterprises for hosting applications, storing and analyzing large datasets, developing artificial intelligence and machine learning applications, running containerized workloads, and building scalable web applications. Organizations can combine services such as Compute Engine, Cloud Storage, VPC, and Google Kubernetes Engine to create cloud-based infrastructures.
