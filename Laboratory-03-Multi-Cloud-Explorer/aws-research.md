# AWS Research

## Brief Overview

Amazon Web Services (AWS) is a cloud computing platform that provides a wide range of services for computing, storage, databases, networking, security, analytics, artificial intelligence, and other IT needs. AWS allows organizations to use cloud resources without having to build and maintain all of their own physical infrastructure.

## Global Infrastructure

AWS operates a global cloud infrastructure organized into geographic Regions and Availability Zones. AWS Regions are separate geographic areas, while Availability Zones are isolated locations within a Region. AWS states that its cloud infrastructure spans multiple geographic regions and Availability Zones, allowing organizations to deploy applications closer to users and design systems for high availability and fault tolerance.

## Cloud Management Console

The AWS Management Console is a web-based interface used to access and manage AWS services and resources. Users can select services, configure resources, monitor their cloud environment, and choose the appropriate AWS Region for many regional services.

## Four Core Services

### 1. Amazon EC2

Amazon Elastic Compute Cloud (Amazon EC2) provides virtual servers that organizations can use to run applications and workloads in the cloud.

### 2. Amazon S3

Amazon Simple Storage Service (Amazon S3) is an object storage service used to store and retrieve data such as documents, images, backups, and application files.

### 3. Amazon VPC

Amazon Virtual Private Cloud (Amazon VPC) allows users to create and manage a logically isolated virtual network in AWS where cloud resources can be placed and controlled.

### 4. AWS IAM

AWS Identity and Access Management (IAM) helps organizations control access to AWS resources by managing users, roles, permissions, and authentication.

## Three Advantages

1. **Scalability** – AWS allows organizations to increase or decrease cloud resources based on their workload requirements.

2. **Global Availability** – AWS provides infrastructure in multiple geographic Regions and Availability Zones, helping organizations deploy applications closer to their users and design highly available systems.

3. **Wide Range of Services** – AWS provides many cloud services covering computing, storage, networking, databases, security, analytics, artificial intelligence, and other business requirements.

## Typical Enterprise Use Cases

AWS can be used by enterprises for hosting websites and applications, storing and backing up large amounts of data, running business applications, building scalable systems, disaster recovery, data analytics, and artificial intelligence workloads. Organizations can combine services such as Amazon EC2, Amazon S3, Amazon VPC, and AWS IAM to build and manage secure cloud-based infrastructures.
